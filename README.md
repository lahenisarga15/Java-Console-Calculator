## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Multiple calculations using a loop
- Exit option

## Technologies Used

- Java
- Scanner
- Console Input/Output

## Java Concepts Used

- Methods
- Variables and data types
- Conditional statements
- Switch statement
- Do-while loop
- User input using Scanner

## How It Works

The program displays a menu of arithmetic operations. The user selects an operation and enters two numbers. The corresponding method performs the calculation and displays the result.

The program continues running until the user selects the Exit option.

## Learning Outcome

Through this task, I practiced Java syntax, methods, loops, conditional statements, Scanner input, and basic program logic.
